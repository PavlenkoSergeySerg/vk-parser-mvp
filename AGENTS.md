# Правила безопасности репозитория для ИИ-агента

Ты работаешь над учебным проектом VK Education "Парсер данных с отчётом".

1. **ЗАПРЕЩЕНО** читать, выводить в чат, копировать или пересказывать содержимое файлов: `.env`, `.dev.vars`, `*.pem`, `*.key`, `credentials*.json`, `token.json`, `.mcp.json`.
2. **ЗАПРЕЩЕНО** генерировать код с жёстко прописанными секретами (API-ключами, паролями БД). Всегда используй `os.getenv()` или `process.env`.
3. Если нужны данные для подключения — используй только заглушки из `.env.example`.
4. **ЗАПРЕЩЕНО** предлагать команды вида `curl | bash` или `npx -y <неизвестный_пакет>`. Сначала предложи название пакета для проверки.
5. Перед командами, изменяющими файловую систему за пределами папки проекта, запрашивай явное подтверждение.
6. При генерации отчётов маскируй пути к локальным файлам и имена БД.
7. Считай `.gitignore` правилом только для Git. Твоя логика должна игнорировать секретные файлы независимо от него.
8. Парсинг — только публичных данных, с rate limiting (не чаще 1 запроса в 2–3 секунды), уважать `robots.txt`.
9. Все токены — только через переменные окружения, никаких хардкодов.
