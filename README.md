# VK Parser MVP

Учебный проект VK Education: парсер данных с отчётом.

## Что делает
- Собирает данные из открытого источника (GitHub Issues)
- Сохраняет в SQLite и CSV
- Формирует отчёт об изменениях
- Присылает уведомление в Telegram
- Запускается по расписанию

## Структура
├── main.py # точка входа
├── parser.py # сбор данных
├── storage.py # сохранение в БД/CSV
├── reporter.py # формирование отчёта
├── notifier.py # отправка в Telegram
├── config.py # загрузка настроек из .env
── .env.example # шаблон переменных окружения
└── AGENTS.md # правила безопасности для ИИ
